1. Approach - To solve the surface quality control problem, this project utilizes a supervised computer vision approach via an end-to-end Convolutional Neural Network (CNN) prototype. The core goal is to automatically categorize images into one of four distinct surface conditions: Normal (defect-free), Scratch, Dent, or Stain. By leveraging convolutional layers, the model bypasses manual feature extraction, inherently learning to distinguish complex visual anomalies like irregular shapes, lines, and discolorations.
2. Implementation Steps - The project pipeline was systematically executed across the following stages within the development environment:Exploratory Data Analysis (EDA): Analyzed the structure of the dataset by parsing the labels.csv metadata file and examining folder contents to determine target class distributions, count raw data files, and verify image resolutions.Data Preprocessing & Augmentation: * Unified all incoming images by scaling their dimensions to a fixed tensor size of 224 times 224 pixels.Normalized integer pixel intensities from standard range [0, 255] down to float constraints [0.0, 1.0]. Partitioned the raw dataset into an 80% training slice and a 20% testing slice.Applied real-world spatial data augmentation (random rotations, zoom, horizontal flips, and width/height translations) to prevent overfitting.CNN Model Architecture: Built a multi-layer deep learning model featuring cascading Convolutional layers (for feature extraction), MaxPooling layers (for spatial reduction), ReLU activation functions (to map non-linear complexities), a Flatten layer, and Dense/Softmax layers to calculate the final category probabilities.Training & Optimization: Compiled the architecture with the Adam optimizer and Categorical Crossentropy loss function, training the parameters across 15 complete learning epochs.
3. Results & Evaluation OverviewThe model's final performance is preserved and visually mapped across the project directory:Learning Progression (results/accuracy_loss_curves.png): Generated diagnostic trendlines mapping training versus validation accuracy and loss values over the training lifecycle to verify optimal learning convergence.Classification Performance Metrics: Produced a comprehensive classification evaluation report detailing Precision, Recall, and F1-Scores across all four target defect classes.Error Assessment Map (results/confusion_matrix.png): Constructed a clear confusion matrix heatmap layout to track exact model distributions and identify precisely which defect variations are structurally misclassified.Visual Validation Panel (sample_predictions/prediction_outputs.png): Extracted random sample images from the test set pipeline to display the network's final categorical predictions alongside their actual baseline labels and statistical confidence margins.
